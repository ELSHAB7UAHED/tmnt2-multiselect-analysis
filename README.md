# TMNT2 static reverse-engineering package

This archive contains the user-supplied modified game files plus static analysis outputs. No EXE or DLL was executed. `TMNT2-decompiled.c` is Ghidra-reconstructed C-like pseudocode, not the original source code and not guaranteed to compile.

The modified executable differs from the reference in two code locations. The REA reports and focused disassembly document those locations. The full game copy is included only to keep the working set together; do not redistribute it.

Test changes only on a copy you are authorized to modify. Return the changed executable and a short test log if you want another comparison pass.
